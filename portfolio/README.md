# Studio — Design Portfolio

A beautiful, eye-catching design portfolio website built with a comprehensive design system.

## Tech Stack

- **React 19** — UI framework
- **Vite 6** — Build tool & dev server
- **Tailwind CSS 3** — Utility-first styling
- **Framer Motion** — Smooth animations
- **Lucide React** — Icon system

## Design System

The portfolio includes a full token-based design system:

- **Colors** — Canvas, ink, accent, violet, and lime palette
- **Typography** — Syne (display), DM Sans (body), JetBrains Mono (labels)
- **Spacing** — Consistent 4px-based scale
- **Components** — Buttons, badges, cards, and form elements
- **Motion** — Purposeful, smooth, delightful animations

## Getting Started

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:5174](http://localhost:5174) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Sections

1. **Hero** — Bold introduction with animated elements
2. **Marquee** — Scrolling expertise showcase
3. **Work** — Project gallery with hover interactions
4. **About** — Bio, stats, and services
5. **Design System** — Live showcase of tokens and components
6. **Contact** — Form and social links

## Customization

Edit `src/data/content.js` to update:
- Project portfolio items
- Services and stats
- Navigation links
- Design system tokens
