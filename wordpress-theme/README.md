# WordPress Theme — Studio Portfolio

This folder contains the **Studio Portfolio** WordPress theme.

## Quick Start

1. Copy `studio-portfolio/` to `wp-content/themes/` on your WordPress site
2. Activate the theme in **Appearance → Themes**
3. Go to **Portfolio → Add New** to upload your work

See [studio-portfolio/README.md](./studio-portfolio/README.md) for full documentation.

## Theme Highlights

- Blue, black, white, and gold color scheme
- Portfolio hover auto-scroll gallery
- Backend portfolio upload with featured image + gallery
- WordPress Customizer for hero, about, and contact settings
